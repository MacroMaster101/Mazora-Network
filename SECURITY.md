# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public GitHub issue,
discussion, Discord channel, or support form.

Report them privately through GitHub Security Advisories:

1. Open this repository on GitHub.
2. Select **Security → Advisories → Report a vulnerability**.
3. Include the affected route or component, reproduction steps, impact, and any
   supporting screenshots or request/response details with secrets removed.

Do not include passwords, session cookies, access tokens, private Discord
content, personal information, or production database contents in a report.

## Supported version

Security fixes target the current production branch. Older commits, forks, and
local modifications are not supported.

## Safe research

Use local or explicitly authorized test environments. Do not access another
person's account or data, disrupt production, send spam, perform denial-of-
service testing, or modify/delete live records.
